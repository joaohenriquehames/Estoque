
# Back-end do Almoxarifado

**Aluno:Joao Henrique Hames de Campos**  
**Turma:Tecnico em desenvolvimento de sistemas Vespertino**

## Sobre o projeto

Este projeto controla o estoque de produtos de um almoxarifado, registrando entradas e saídas, consultando produtos, calculando o valor do estoque e gerando solicitações de compra.

## Arquivos

- produto.py: contém a classe Produto.
- teste_produto: realize testes do produto
- almoxarifado.py: contém a classe Almoxarifado e seus métodos de controle de estoque.
- teste_almoxarifado.py: realiza os testes do sistema.
